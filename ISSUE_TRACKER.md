## How to Use This Tracker

2. **Update Status:** Change status as you work on fixes
3. **Link Fixes:** Reference PR/branch when fixing
4. **Verify:** Mark as verified after testing

---

## Issue Status Legend

- 🔴 **Critical** - App crashes, security issues, data loss
- 🟠 **High** - Major feature broken, significant UX issues
- 🟡 **Medium** - Minor feature issues, UI inconsistencies
- 🟢 **Low** - Cosmetic issues, minor improvements
- ✅ **Fixed** - Issue resolved and verified
- 🚧 **In Progress** - Currently being worked on
- 📋 **Backlog** - Planned for future

**Expected Behavior:**
[What should happen]

**Actual Behavior:**
[What actually happens]

**Environment:**
- Browser: [Browser and version]

- Device: [Desktop/Mobile]
- User Role: [Logged in/Logged out/Subscription tier]

**Screenshots/Logs:**
[Attach screenshots or console logs]

**Files Involved:**

- `path/to/file2.ts`

[Analysis of what's causing the issue]

[How you plan to fix it]

**Branch/PR:**

- [ ] Code reviewed
