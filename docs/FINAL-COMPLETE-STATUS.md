## 🎯 Navigation Structure

### Top Navbar
```
☰  +AI    Chat  Explore    ✉  (N)
                          ②
```

- ☰ = Hamburger menu (simple nav)
- Chat/Explore = Content modes
- ✉ = Messages (always accessible)
- (N) = Avatar → `/profile`

### Routes
- `/` - Chat with +AI
- `/messages` - Your message threads
- `/messages/{threadId}` - Conversation
- `/messages/new` - Start new conversation
- `/profile` - Your profile (tabs: Profile | Cloud | Activity | Settings)
- `/u/{handle}` - Public profile pages
- `/cloud` - Vault/Cloud storage
- `/dev/pwa` - PWA diagnostics
